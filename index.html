1. Choisir votre archive locale

Jeu marble et BIOS Atari System 1 facultatif : les 30 fichiers attendus peuvent être répartis entre les deux ZIP. Les fichiers restent locaux, sans upload ni stockage persistant dans le navigateur.

En attente de votre archive. Sans ROM, le lancement du jeu ne peut pas être vérifié.

2. Lancer le cœur et observer le jeu

Après vérification, un bouton de démarrage apparaît dans le cadre. Vérifier le mode attract et l’audio. Utiliser ensuite Crédit, Start joueur 1, puis Capturer le trackpad. Le confort des commandes doit être essayé par Michel.

Boost prêt : maintenir Espace et guider au trackpad pendant le jeu. Relâcher Espace rend le contrôle normal. Échap met en pause.

Diagnostics de faisabilité

Capturer → faire une accélération → Échap → Copier les diagnostics. Le relevé conserve le mouvement le plus fort, même si tu as bougé un peu avant.

Pour comparer gestes lents et rapides : peakRaw est le plus grand delta reçu, peakSent le plus grand delta après gain, peakPending le pic accumulé avant lecture du cœur. saturated signale un écrêtage dans notre raccord. Ces mesures portent sur les commandes, pas sur la vitesse de la bille. nativeSampling conserve les extrema signés (minX/maxX/minY/maxY) du dernier poll natif observé après chaque itération de l'émulateur. reversalsX/Y compte les inversions observées par axe, utiles pour examiner les gestes de freinage. Cet échantillonnage n'est pas un relevé exhaustif de toutes les lectures du cœur. Les mesures restent disponibles après Échap. 


      

      

        Fichiers attendus dans marble.zip
        

          Tailles et SHA-1 sont vérifiés sur les données décompressées. Les
          archives FBNeo et MAME ne sont pas interchangeables par simple
          renommage. Les fichiers système peuvent être fournis dans le ZIP du
          jeu ou dans le champ BIOS séparé. Les noms Atari comme 136032.205.l13
          sont reconnus après vérification des empreintes. Un ZIP compatible est
          assemblé uniquement en mémoire ; tes archives originales restent
          inchangées.
